# Radiation Monitoring System

Система мониторинга радиационной обстановки.

## Технологии

- Java 21
- Spring Boot 3.5
- PostgreSQL 16
- Nginx
- Google Cloud Platform
- Leaflet
- Chart.js

## Возможности

- Мониторинг датчиков
- Мониторинг станций
- Heartbeat Raspberry Pi
- Карта станций
- История измерений
- События и тревоги
- HTTPS доступ
